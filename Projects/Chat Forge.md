Chat Forge is an app that uses AI to synthesize the dataset.
The app will have these tabs.

* Chat tab to test the model
* Dataset tab to explore and edit the dataset. This tab will have these features.
  * The datasets are grouped by category; every category is a separate file (CSV for chat-like datasets with question-answer or a text file).
  * The page will have a table to show the CSV dataset in a table or to show the text files
  * The page will have a filter to select what category will be used for the chat tab.
* AI processing tab: This will be used to generate updates and modify the datasets. It will have 2 sections.
  * A section to process or create the datasets
  * A section to test the chat with AI; the AI will chat with the generated model. If the chat fails to respond, the AI will give it a response. This will be added into a separate dataset
